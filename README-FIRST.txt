IDCG Tender Platform — first-stage Supabase integration starter

This package is a foundation only. It does not connect the live dashboard, create a Supabase project, or import the 78 tender records.

Extract this folder, then upload its files to the GitHub branch development/supabase-integration. Preserve the existing index.html for now.
Review supabase/schema.sql and run it only in a fresh Supabase project.
Never commit supabase/config.js or any service-role key/database password.
